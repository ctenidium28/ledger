# 知識台帳 — 一次資料の記事作成指示

本ファイルは、知識台帳の「資料」ページ（`content/resources/`）に一次資料を記事として保存する際の指示である。一次資料の翻訳だけでなく、特定の問いや目的に沿った一次資料の収集・抜粋・整理にも適用するためのファイルである。

プロジェクト全体の方針は [general.md](./general.md) に従う。資料記事の目的は、原資料の内容を後から正確に参照できるようにすることであり、一般向けの解説記事や会話上の回答を作成することとは区別する。

現時点では、以下の翻訳に関する指示を定める。

## 1. 翻訳の方針

### 1.1 原文への忠実性

- 原則として原語の本文を基礎に訳出する。既存の翻訳や注釈は、語義・構文・文脈の確認に用いる参考資料として扱う。
- 原文を直接確認できなかった場合はその旨を明記し、他言語訳に基づく重訳を原典からの直接訳として扱わない。実際に確認していない資料を参照したと記述しない。
- 原文の意味、論理関係、語の区別を維持しながら、自然で明瞭な日本語に訳す。原文の曖昧さを訳者の解釈によって不用意に解消しない。
- 全文翻訳を求められた場合は、指定範囲を省略・要約せずに訳す。原文にある反復や定型句も維持し、訳者が冗長と判断したことを理由に削除しない。
- 原資料の章・節・項・偈などの区分と番号を維持し、後から原文の該当箇所を特定できるようにする。訳者が補った見出しは原文の見出しと混同させない。

### 1.2 原語と訳語

**重要な概念については、日本語訳だけでなく原語を重視する。**

- 思想・論証の理解に重要な語、訳語だけでは意味の範囲が伝わりにくい語、複数の解釈が可能な語などは、必要に応じて本文中で原語を併記する。例：有（sat）、自己（ātman）。
- 原語の表記には、その言語に適した文字または標準的な翻字方式を用いる。サンスクリット語の場合は原則として IAST を用い、発音区別符号を保持する。
- 同じ概念に対する訳語は可能な限り統一する。ただし、文脈によって語義が異なる場合は一律に同じ訳語を当てない。
- 原語が異なる概念を、後世の思想や一般的な訳語に合わせて同一の語に置き換えない。例えば『チャーンドーギヤ・ウパニシャッド』第6章の sat と brahman の区別を維持する。
- 原語の併記は必要な箇所に限り、すべての単語や同一語の出現ごとに機械的に付加しない。原文全文の併載も、指定がない限り必須としない。

### 1.3 訳注と解釈

- 訳注は、語義・構文・訳語の選択、原文の異読、翻訳上の不確かさなど、本文を正確に理解するために必要な場合に付す。
- 訳注は該当箇所を特定できるようにし、翻訳本文と明確に区別する。すべての節に形式的に訳注を設ける必要はない。
- 原文にない説明や訳者の解釈を、原資料の記述であるかのように本文へ混入させない。補訳が不可欠で、その有無が理解に影響する場合は括弧や訳注で明示する。
- 既存の注釈者の見解と訳者自身の判断を区別する。後世の思想体系によって原資料の意味を先取りしない。
- 詳細な思想解説、歴史的背景、学説比較などは、ユーザーから求められた場合に限り追加する。翻訳上の問題を説明するために必要な最小限の補足は認める。

### 1.4 資料記事としての構成

資料記事は原則として、対象資料を特定するための情報、翻訳本文、必要な訳注、出典から構成する。会話の回答をそのまま転載するのではなく、後から参照するための独立した資料として整える。

- 記事の題名は YAML frontmatter に記載し、本文の冒頭に同一の題名を重複して置かない。
- 使用した原典・底本・版、翻訳対象の範囲、参照した既訳・注釈を必要に応じて簡潔に明示する。詳細な翻訳方針を記事ごとに繰り返さない。
- 重要原語・訳語の一覧、章節の構成表、要約、総括、精読用の付録などは、ユーザーから明示的な指示がない限り追加しない。冒頭の訳語一覧など、実質的に同様の機能を持つ部分も同じ扱いとする。
- 会話的な前置き、作業経過の報告、完了宣言、次の学習への提案などを含めない。既に本文や訳注で説明した事項を末尾で繰り返さない。
- 出典は実際に参照した資料に限り、資料名・版や訳者・該当箇所・URLなど、再確認に必要な情報を記載する。ChatGPTの引用UIに由来するアイコン、断片的なドメイン名や引用件数、不要なトラッキング用パラメータなどを記事に残さない。
- 翻訳本文の文体は原資料の性質に合わせる。通常の会話における「です・ます調」の指定を翻訳本文に機械的に適用しない。

## 2. 保存形式

資料記事は `content/resources/*.md` に YAML frontmatter と Markdown 本文を用いて保存する。題名（`title`）と執筆・加筆タグ（`attribution`）は現行の Pages CMS の規定に従う。LLM が新規に作成した翻訳記事は `attribution: llm` とする。このタグは翻訳記事の作成主体を示すものであり、原資料の著者を示すものではない。

リポジトリへの書き込みはユーザーが明示的に許可した場合に限る。既存の記事は個別の依頼なく書き換えない。
