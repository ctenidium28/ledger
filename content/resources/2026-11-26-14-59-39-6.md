# **『チャーンドーギヤ・ウパニシャッド』第6章 全文和訳**

（Chāndogya Upaniṣad, Ṣaṣṭha Prapāṭhaka）

## **翻訳方針**

第6章の全16節・69項（6.1.1〜6.16.3）を、省略せずに訳出します。今回はロケスワラナンダやシャンカラによる詳細な解説を省き、ウパニシャッド本文そのものの理解に必要な訳注のみを付します。

訳出にあたっては、[GRETILのサンスクリット原典](https://gretil.sub.uni-goettingen.de/gretil/1_sanskr/1_veda/4_upa/chup___u.htm?utm_source=chatgpt.com)を基礎とし、[Advaita Śāradā収録の原典・シャンカラ注](https://www.advaitasharada.sringeri.net/read/chandogya-bhashya/6/?utm_source=chatgpt.com)および[マックス・ミュラーによる英訳（1879年）](https://en.wikisource.org/wiki/Sacred_Books_of_the_East/Volume_1/Kh%C3%A2ndogya-upanishad/Sixth_Prap%C3%A2thaka?utm_source=chatgpt.com)を参照します。

### **主要な訳語**

| サンスクリット     | 本文での訳語        |
| ----------- | ------------- |
| sat         | 有（サット）        |
| asat        | 無（アサット）       |
| ātman       | 自己（アートマン）     |
| jīva        | 生命、生命主体（ジーヴァ） |
| devatā      | 神的原理          |
| parā devatā | 最高の神的原理       |
| tejas       | 火・熱・光（テージャス）  |
| āpas        | 水             |
| anna        | 食物（アンナ）       |
| prāṇa       | 生命息（プラーナ）     |
| manas       | 心（マナス）        |
| vāc         | 言葉・発語         |
| aṇiman      | 微細な本質         |
| nāmarūpa    | 名称と形態         |
| satya       | 真実、真なるもの      |
| sampad      | 合一する、帰入する     |

**特に重要なのは、第6章で世界の究極的な根拠を表す語が、ブラフマン（brahman）ではなく、主としてサット（sat）であることです。**

6.3.2ではそれが神的原理（devatā）と呼ばれ、6.8.6および6.15では最高の神的原理（parā devatā）と呼ばれます。そして6.8.7以降ではアートマン（ātman）と同一視されます。

これらをブラフマンとして理解するのはヴェーダーンタの解釈として妥当ですが、本文訳では原語の違いを維持します。

# **第1節　原因を知ることによって結果を知る**

## **6.1.1**

かつて、アールニの子シュヴェータケートゥがいた。

その父は彼に言った。

「シュヴェータケートゥよ、修学者としての生活（brahmacarya）を送りなさい。愛しい息子よ、私たちの家系では、学問を修めず、ただ名ばかりのバラモンとなるような者はいないのだから。」

## **6.1.2**

そこで彼は十二歳のときに師のもとへ赴き、二十四歳になるまでにすべてのヴェーダを学び終えた。

そして、自尊心が強く、自分を学識ある者と思い込み、傲慢な態度で帰ってきた。

父は彼に言った。

## **6.1.3**

「シュヴェータケートゥよ、愛しい息子よ。お前はそのように自尊心が強く、自分を学識ある者と思い、傲慢になっているが、あの教え（ādeśa）についても尋ねたのか。

それによって、まだ聞いたことのないものが聞かれたものとなり、まだ考えたことのないものが考えられたものとなり、まだ知らなかったものが知られたものとなる、という教えについて。」

「尊き父上、その教えとは、どのようなものなのでしょうか。」

## **6.1.4**

「愛しい息子よ、例えば、一塊の粘土を知ることによって、粘土から作られたあらゆるものが知られるようになる。

変形したものは、言葉に依拠する名称にすぎない。真実であるのは、ただ粘土だけである。」

## **6.1.5**

「愛しい息子よ、例えば、一塊の金を知ることによって、金から作られたあらゆるものが知られるようになる。

変形したものは、言葉に依拠する名称にすぎない。真実であるのは、ただ金だけである。」

## **6.1.6**

「愛しい息子よ、例えば、一つの鉄製の爪切りを知ることによって、鉄から作られたあらゆるものが知られるようになる。

変形したものは、言葉に依拠する名称にすぎない。真実であるのは、ただ鉄だけである。

愛しい息子よ、あの教えとは、このようなものなのだ。」

## **6.1.7**

「きっと、私の尊敬する先生方は、このことをご存じなかったのでしょう。

もしご存じだったならば、どうして私に教えてくださらなかったのでしょうか。

ですから、尊き父上、どうかあなた自身が私にこのことを教えてください。」

「よかろう、愛しい息子よ」と父は言った。

### **第1節の訳注**

- **Brahmacarya（6.1.1）**：ここでは、師のもとでヴェーダを学ぶ修学期の生活を意味する。単に禁欲や独身生活を指すのではない。
- **Brahmabandhu（6.1.1）**：字義的にはバラモンの縁者。家系上はバラモンであっても、それにふさわしい学識や行いを欠く者を指す。
- **Ādeśa（6.1.3）**：教示、指示、教え。本文ではこの時点で、教えの対象が何であるかはまだ明示されていない。
- **Vācārambhaṇaṃ vikāro nāmadheyam（6.1.4〜6）**：「変形したものは、言葉に依拠する名称にすぎない」。*vācārambhaṇa* の解釈には幅があるが、素材とその変形物との実在性の違いを論じる重要な表現である。
- **Lohamaṇi（6.1.5）**：金属の塊。シャンカラは金（suvarṇa）の塊と解釈しているため、その解釈に従った。
- **Nakhanikṛntana（6.1.6）**：爪を切る道具。現代の爪切りと同じ構造を持つとは限らない。

# **第2節　サットと世界の生成**

## **6.2.1**

「愛しい息子よ、はじめ、この世界はただ有（sat）であった。ただ一つであり、第二のものはなかった。

これについて、ある者たちは次のように言う。

『はじめ、この世界はただ無（asat）であった。ただ一つであり、第二のものはなかった。その無から有が生じたのだ』と。」

## **6.2.2**

父は言った。

「しかし、愛しい息子よ、どうしてそのようなことがあり得ようか。

無から有が、どうして生じるというのか。

いや、愛しい息子よ、はじめ、この世界はただ有であった。ただ一つであり、第二のものはなかった。」

## **6.2.3**

その有は考えた。

「私は多数となろう。生まれ出よう」と。

そして、それはテージャス（tejas）を生み出した。

そのテージャスは考えた。

「私は多数となろう。生まれ出よう」と。

そして、それは水を生み出した。

それゆえ、人がどこであれ苦しみ悲しむとき、あるいは汗をかくとき、そこに水が生じるのは、まさしくテージャスからなのである。

## **6.2.4**

それらの水は考えた。

「私たちは多数となろう。生まれ出よう」と。

そして、それらは食物（anna）を生み出した。

それゆえ、どこであれ雨が降るところには、食物が豊かに生じる。

まさしく水から、食べられるものが生じるのである。

### **第2節の訳注**

- **Sad eva somyedam agra āsīd ekam evādvitīyam（6.2.1）**：「愛しい息子よ、はじめ、この世界はただ有であった。ただ一つであり、第二のものはなかった」。ここに *brahman* という語は用いられていない。
- **Advitīya**：第二のものを持たない。不二一元論（advaita）の重要な典拠となった語だが、この語だけで後世のシャンカラの哲学体系全体が表明されているわけではない。
- **Asat**：非存在、無。文献や文脈によっては未顕現の状態を意味することもあるため、ヴェーダ文献に現れるすべての *asat* を絶対的な無と解釈することはできない。
- **Aikṣata（6.2.3）**：見た、考えた、熟慮した。サットに意図的な働きが帰属されている。
- **Bahu syāṃ prajāyeya（6.2.3）**：「私は多数となろう。生まれ出よう」。別の存在を作ろうとする表現ではなく、サット自身が多数となるという一人称の表現である。
- **Anna（6.2.4）**：通常は食物を意味するが、三つの根本要素の一つとして用いられる場合、シャンカラは大地（pṛthivī）と解釈する。本文にその語が直接現れるわけではないため、「食物」という訳を保持した。

なお、指定されたGRETILの旧版には6.2.4が欠落しているため、この項はAdvaita Śāradā収録の原典によって補っています。

# **第3節　生命主体の進入と三重化**

## **6.3.1**

これらの生きものには、実に三種類の発生源（bīja）だけがある。

卵から生まれるもの（āṇḍaja）、生きものから生まれるもの（jīvaja）、芽を出して生まれるもの（udbhijja）である。

## **6.3.2**

その神的原理（devatā）は考えた。

「さあ、私はこの生命ある自己（jīvena ātmanā）として、これら三つの神的原理の中へ入り込み、名称と形態（nāmarūpa）を分化させよう。」

## **6.3.3**

「そして、それら一つ一つを三重のものにしよう」と。

その神的原理は、まさしくこの生命ある自己として、これら三つの神的原理の中へ入り込み、名称と形態を分化させた。

## **6.3.4**

そして、それら一つ一つを三重のものにした。

「愛しい息子よ、これら三つの神的原理のそれぞれが、どのようにして三重のものとなるのか、それを私から学びなさい。」

### **第3節の訳注**

**Dev atā（devatā、6.3.2〜4）：神的原理**

ここで *devatā* という語は、二種類の対象に用いられている。

| 原文                             | 指示対象       |
| ------------------------------ | ---------- |
| seyaṃ devatā（その神的原理）           | サット        |
| imās tisro devatāḥ（これら三つの神的原理） | テージャス・水・食物 |

同じ語が、世界の根本的な存在と、それから生じた三つの要素の双方に用いられている。原文ではサットを *brahman* と呼んでいない。

**Anena jīvena ātmanā（6.3.2〜3）：この生命ある自己として**

*jīvena* と *ātmanā* はともに具格である。したがって、生命ある自己として、あるいは生命ある自己を介して、という意味に解釈できる。

ここは、世界の根本原理と個々の生命との関係を理解するうえで極めて重要な箇所である。

シャンカラはジーヴァを神的原理の反映（ābhāsa）として解釈するが、本文自体には反映という説明はない。

**Nāmarūpe vyākaravāṇi（6.3.2）：名称と形態を分化させよう**

*Vyākaroti* は、区別する、分化させる、明確にする、という意味を持つ。

ここで述べられているのは、名称と形態によって区別される多様な世界の成立である。本文は、それを単なる錯覚であるとは明示していない。

**Trivṛt（6.3.3〜4）：三重の**

後世に三重化（trivṛtkaraṇa）と呼ばれる教説である。

テージャス・水・食物のそれぞれが、ほかの二つの要素をも含むものとなることを指す。具体的な混合比率は本文に示されていない。

# **第4節　三つの形態による世界の構成**

## **6.4.1**

火（agni）の赤い形態は、テージャスの形態である。

白い形態は、水のものである。

黒い形態は、食物のものである。

こうして、火から火としての固有性（agnitva）は消え去った。

変形したものは、言葉に依拠する名称にすぎない。真実であるのは、ただ三つの形態だけである。

## **6.4.2**

太陽の赤い形態は、テージャスの形態である。

白い形態は、水のものである。

黒い形態は、食物のものである。

こうして、太陽から太陽としての固有性は消え去った。

変形したものは、言葉に依拠する名称にすぎない。真実であるのは、ただ三つの形態だけである。

## **6.4.3**

月の赤い形態は、テージャスの形態である。

白い形態は、水のものである。

黒い形態は、食物のものである。

こうして、月から月としての固有性は消え去った。

変形したものは、言葉に依拠する名称にすぎない。真実であるのは、ただ三つの形態だけである。

## **6.4.4**

稲妻の赤い形態は、テージャスの形態である。

白い形態は、水のものである。

黒い形態は、食物のものである。

こうして、稲妻から稲妻としての固有性は消え去った。

変形したものは、言葉に依拠する名称にすぎない。真実であるのは、ただ三つの形態だけである。

## **6.4.5**

かつて、このことを知っていた偉大な家長たち、ヴェーダに精通した者たちは、こう語ったものである。

「今や、誰も私たちに、まだ聞いたことのないもの、まだ考えたことのないもの、まだ知らなかったものを示すことはできない。」

彼らは、これら三つのものから知識を得ていたのである。

## **6.4.6**

何かが赤く見えるならば、それをテージャスの形態であると彼らは知った。

何かが白く見えるならば、それを水の形態であると彼らは知った。

何かが黒く見えるならば、それを食物の形態であると彼らは知った。

## **6.4.7**

何かが見知らぬもののように思われても、それはまさしくこれらの神的原理が組み合わされたものであると、彼らは知った。

「愛しい息子よ、これら三つの神的原理が人間に入って、それぞれ三重のものとなるのはどのようにしてか、それを私から学びなさい。」

### **第4節の訳注**

**Agniとtejas（6.4.1）**

両者とも「火」と訳されることがあるが、この箇所では明確に区別されている。

- *Agni*：具体的に経験される火。
- *Tejas*：その火を構成する根本的な要素の一つ。

この宇宙論では、具体的な火であるアグニも、テージャスだけで構成されているわけではない。

**Rūpa：形態、色、外見**

この箇所では赤・白・黒という色彩として現れるが、原語は色彩だけでなく形態や外見も意味する。

| 神的原理  | 対応する色     |
| ----- | --------- |
| テージャス | 赤（rohita） |
| 水     | 白（śukla）  |
| 食物    | 黒（kṛṣṇa）  |

**Apāgād agner agnitvam（6.4.1）：火から火としての固有性が消え去った**

ここで火が物理的に消滅したという意味ではない。火というものを三つの構成要素に還元して理解すれば、それらとは別に火としての固有の実在性を想定する必要がなくなる、という趣旨である。

6.1の粘土の例における原理が、ここでは自然現象に適用されている。

# **第5節　食物・水・テージャスと人体**

## **6.5.1**

食べられた食物は、三つに分かれる。

その最も粗大な部分は糞便となる。

中間の部分は肉となる。

最も微細な部分は心（manas）となる。

## **6.5.2**

飲まれた水は、三つに分かれる。

その最も粗大な部分は尿となる。

中間の部分は血となる。

最も微細な部分は生命息（prāṇa）となる。

## **6.5.3**

摂取されたテージャスは、三つに分かれる。

その最も粗大な部分は骨となる。

中間の部分は骨髄となる。

最も微細な部分は言葉（vāc）となる。

## **6.5.4**

「愛しい息子よ、実に、心は食物から成り、生命息は水から成り、言葉はテージャスから成るのである。」

「尊き父上、どうかさらに私に教えてください。」

「よかろう、愛しい息子よ」と父は言った。

### **第5節の訳注**

**Manas：心**

思考・記憶・認識などに関わる心的機能を意味する。アートマンそのものとは区別される。

この区別は重要である。後に不死であると説かれる生命主体やアートマンとは異なり、心はここで食物に由来するものとされている。

**Prāṇa：生命息**

単なる呼吸や空気だけでなく、生命を維持する働きを含む。プラーナとアートマンも本文では区別されている。

**Tejo 'śitam（6.5.3）：摂取されたテージャス**

火を直接食べるという意味ではない。シャンカラは油や精製バターなど、テージャスに属する食物の摂取として解釈する。

三要素と人体との対応は次のようになる。

| 由来    | 粗大な部分 | 中間の部分 | 微細な部分 |
| ----- | ----- | ----- | ----- |
| 食物    | 糞便    | 肉     | 心     |
| 水     | 尿     | 血     | プラーナ  |
| テージャス | 骨     | 骨髄    | 言葉    |

これは古代インドにおける身体と精神の生成論であり、現代の生理学における説明とは異なる。

# **第6節　微細な部分の上昇**

## **6.6.1**

「愛しい息子よ、凝乳を攪拌すると、その微細な部分が上方へと浮かび上がる。

それがバターとなる。」

## **6.6.2**

「まさしくそれと同じように、愛しい息子よ、食べられた食物の微細な部分は上方へと昇る。

それが心となる。」

## **6.6.3**

「愛しい息子よ、飲まれた水の微細な部分は上方へと昇る。

それが生命息となる。」

## **6.6.4**

「愛しい息子よ、摂取されたテージャスの微細な部分は上方へと昇る。

それが言葉となる。」

## **6.6.5**

「愛しい息子よ、実に、心は食物から成り、生命息は水から成り、言葉はテージャスから成るのである。」

「尊き父上、どうかさらに私に教えてください。」

「よかろう、愛しい息子よ」と父は言った。

### **第6節の訳注**

**Aṇiman：微細な本質、微細な部分**

ここで凝乳・食物・水・テージャスについて用いられている *aṇiman* は、6.8.7以降で世界の根本的な存在を表すためにも使われる語である。

しかし、この語自体が常にアートマンやサットを意味するわけではない。

ここでは、それぞれの物質に含まれる微細な部分を指している。

**Annamayaṃ manaḥ：心は食物から成る**

*-maya* は「……から成る」「……を素材とする」などの意味を持つ。

したがって、単に食物が心の働きに影響するというだけでなく、心そのものが食物に由来するという主張になっている。

# **第7節　断食による心の働きの検証**

## **6.7.1**

「愛しい息子よ、人間（puruṣa）は十六の部分（kalā）から成っている。

十五日間、食物を食べてはならない。ただし、水は好きなだけ飲みなさい。

生命息は水から成るので、水を飲んでいれば、生命息が断たれることはない。」

## **6.7.2**

そこでシュヴェータケートゥは十五日間、食物を食べなかった。

その後、父のもとへ来て尋ねた。

「父上、何を唱えればよいのでしょうか。」

「愛しい息子よ、リチュ（ṛc）の詩句、ヤジュス（yajus）の祭詞、サーマン（sāman）の歌を唱えなさい。」

彼は答えた。

「父上、それらがどうしても思い浮かびません。」

## **6.7.3**

父は言った。

「愛しい息子よ、例えば、大きく燃えていた火のうち、蛍ほどの大きさの燃えさしが一つだけ残っていたとする。

それでは、もはや多くのものを燃やすことはできない。

それと同じように、愛しい息子よ、お前の十六の部分のうち、今はただ一つの部分だけが残っている。

そのため、今のお前にはヴェーダを思い出すことができないのだ。

食事をしなさい。そうすれば、私の言うことが分かるだろう。」

## **6.7.4**

そこで彼は食事をした。

その後、再び父のもとへ赴いた。

父が何を尋ねても、彼はすべて答えることができた。

## **6.7.5**

父は彼に言った。

「愛しい息子よ、例えば、大きく燃えていた火のうち、蛍ほどの大きさの燃えさしが一つだけ残っていたとする。

それに草を加えて再び燃え上がらせれば、それによって再び多くのものを燃やすことができる。」

## **6.7.6**

「それと同じように、愛しい息子よ、お前の十六の部分のうち、一つの部分だけが残っていた。

それが食物によって養われ、再び燃え上がったのである。

そのため、今のお前はヴェーダを思い出すことができる。

愛しい息子よ、実に、心は食物から成り、生命息は水から成り、言葉はテージャスから成るのである。」

こうして彼は父の教えを理解した。実に、理解したのである。

### **第7節の訳注**

**Ṣoḍaśakalaḥ puruṣaḥ（6.7.1）：十六の部分から成る人間**

*Kalā* は部分、分け前、構成部分などを意味する。

ここでは十六の部分の具体的な内訳は列挙されていない。後世の文献に登場する十六の構成原理を、そのままこの箇所に当てはめるべきではない。

また、十五日間の断食によって十五の部分が失われ、一つだけが残るという説明は、本文独自の身体観に基づくものである。

本節の主題は、心の働きが食物に依存していることを、シュヴェータケートゥ自身の経験によって理解させることである。これは現代医学的に安全な断食方法を示す記述ではない。

# **第8節　睡眠・生命の根源・自己の本質**

## **6.8.1**

ウッダーラカ・アールニは、息子シュヴェータケートゥに言った。

「愛しい息子よ、睡眠の本質を私から学びなさい。

人が眠っていると言われるとき、その人は有（sat）と合一しているのである。自分自身へと帰っているのである。

それゆえ、人々はその人について『眠っている』（svapiti）と言う。

自分自身（sva）へと帰っている（apīta）からである。」

## **6.8.2**

「例えば、糸につながれた鳥が、あらゆる方向へ飛んでいっても、ほかに落ち着く場所を見いだせず、ついには自分がつながれているところへ戻ってくるように、

まさしくそれと同じように、愛しい息子よ、心（manas）はあらゆる方向へ飛んでいっても、ほかに落ち着く場所を見いだせず、ついには生命息（prāṇa）に帰依する。

愛しい息子よ、心は生命息につながれているのである。」

## **6.8.3**

「愛しい息子よ、空腹と渇きについて私から学びなさい。

人が空腹であると言われるとき、水がその人の食べたものを運んでいるのである。

牛を導く者、馬を導く者、人を導く者と言うように、水は食物を導くもの（aśanāyā）と呼ばれる。

そこで、愛しい息子よ、ここに生じたこの芽について考えなさい。

これが根を持たないということはあり得ない。」

## **6.8.4**

「その根は、食物以外のどこにあるだろうか。

まさしくそれと同じように、愛しい息子よ、食物を芽として、その根である水を探し求めなさい。

水を芽として、その根であるテージャスを探し求めなさい。

テージャスを芽として、その根である有（sat）を探し求めなさい。

愛しい息子よ、これらすべての生きものは、有を根とし、有を住処とし、有を存立の基盤としているのである。」

## **6.8.5**

「また、人が渇いていると言われるとき、テージャスがその人の飲んだものを運んでいるのである。

牛を導く者、馬を導く者、人を導く者と言うように、テージャスは水を導くもの（udanyā）と呼ばれる。

そこで、愛しい息子よ、ここに生じたこの芽について考えなさい。

これが根を持たないということはあり得ない。」

## **6.8.6**

「その根は、水以外のどこにあるだろうか。

愛しい息子よ、水を芽として、その根であるテージャスを探し求めなさい。

テージャスを芽として、その根である有を探し求めなさい。

愛しい息子よ、これらすべての生きものは、有を根とし、有を住処とし、有を存立の基盤としているのである。

これら三つの神的原理が人間に入って、それぞれ三重のものとなるのはどのようにしてか、それについてはすでに述べたとおりである。

愛しい息子よ、人が死にゆくとき、その言葉は心へと帰入し、心は生命息へと帰入し、生命息はテージャスへと帰入し、テージャスは最高の神的原理（parā devatā）へと帰入する。」

## **6.8.7**

「この微細な本質（aṇiman）こそ、この世界のすべてが自己としているものである。

それが真実である。それが自己（ātman）である。

**シュヴェータケートゥよ、汝はそれである（tat tvam asi）。**」

「尊き父上、どうかさらに私に教えてください。」

「よかろう、愛しい息子よ」と父は言った。

### **第8節の訳注**

**Satā sampanno bhavati（6.8.1）：有と合一する**

睡眠中の人間がサットと合一するという教説である。夢のない深い眠りを指すと一般に解釈される。

本文は、この合一がアートマンの消滅であるとは述べていない。

**Svapiti・svam apītaḥ（6.8.1）**

「眠る」を意味する *svapiti* を、*svam apītaḥ*（自分自身へと帰った）と関連づける語源的説明である。これはウパニシャッドに特徴的な語義解釈であり、現代の歴史言語学における語源説明とは区別する必要がある。

**Śuṅgaとmūla（6.8.3〜6）：芽と根**

「芽」は結果、「根」はその原因を表す。6.8.3および6.8.5の「この芽」は、文脈上、人間の身体を指すと解釈される。

**Sanmūlāḥ, sadāyatanāḥ, satpratiṣṭhāḥ（6.8.4、6.8.6）**

- *Sanmūla*：有を根とする。
- *Sadāyatana*：有を住処・拠り所とする。
- *Satpratiṣṭha*：有を存立の基盤とする。

ここでは、サットが生命の起源であるだけでなく、現在の生命の存立を支えるものであることも説かれている。

**Parasyāṃ devatāyām（6.8.6）：最高の神的原理へ**

原語は *parā devatā* の処格であり、*brahman* でも *paramātman*（最高のアートマン）でもない。

死に際しての帰入の順序は、次のとおりである。

**言葉（vāc）**

**心（manas）**

**生命息（prāṇa）**

**テージャス（tejas）**

**最高の神的原理（parā devatā）**

文脈上、サットを指す

**Aitadātmyam idaṃ sarvam（6.8.7）：この世界のすべてがそれを自己としている**

単に「すべてのものの中にそれが存在する」という表現よりも強い意味を持つ。

世界のあらゆるものが、その微細な本質を自己としている、あるいはその本質によって自己を成り立たせている、という表現である。

**Tat tvam asi（6.8.7）：汝はそれである**

第6章を代表する教説であり、後世には大聖句（mahāvākya）の一つとされる。

文脈上、*tat*（それ）は先に述べられた微細な本質、すなわちサットを指す。*tvam* はシュヴェータケートゥに向けられた二人称代名詞である。

ここから6.16.3まで、この教説が合計九回繰り返される。

# **第9節　蜂蜜の比喩**

## **6.9.1**

「愛しい息子よ、例えば、蜜蜂が蜂蜜を作るとき、さまざまな場所にある樹木の汁を集め、それらの汁を一つのものにする。」

## **6.9.2**

「それらの汁は、そこにおいて、

『私はあの樹木の汁である』

『私はこの樹木の汁である』

という区別を持たなくなる。

まさしくそれと同じように、愛しい息子よ、これらすべての生きものは、有（sat）と合一しても、自分たちが有と合一していることを知らないのである。」

## **6.9.3**

「それらはこの世界において、虎であれ、獅子であれ、狼であれ、猪であれ、虫であれ、飛ぶ虫であれ、刺す虫であれ、蚊であれ、それぞれが何であったにせよ、再びそのものとなる。」

## **6.9.4**

「この微細な本質こそ、この世界のすべてが自己としているものである。

それが真実である。それが自己である。

**シュヴェータケートゥよ、汝はそれである（tat tvam asi）。**」

「尊き父上、どうかさらに私に教えてください。」

「よかろう、愛しい息子よ」と父は言った。

### **第9節の訳注**

**Sati sampadya na viduḥ（6.9.2）：有と合一しても知らない**

有と合一することと、有との同一性を認識することが区別されている。

前節で説かれたように、生きものは睡眠中にサットと合一する。しかし、そのことを自覚しているわけではない。

**Yad yad bhavanti tad ābhavanti（6.9.3）：それぞれが何であれ、再びそのものとなる**

この文章には、合一を経た後にも、以前の存在としての連続性が保たれることが示されている。

シャンカラはこれを、過去の行為（karma）や潜在的傾向（vāsanā）が保持されることによって説明する。

しかし、この項の本文にはカルマやヴァーサナーという語は現れない。また、睡眠からの覚醒と死後の再生の区別も明示されていない。

それらは海から海へと帰っていく。

『私はあの河川である』

## **6.10.2**

「まさしくそれと同じように、愛しい息子よ、これらすべての生きものは、有（sat）から来ても、自分たちが有から来たことを知らない。

それらはこの世界において、虎であれ、獅子であれ、狼であれ、猪であれ、虫であれ、飛ぶ虫であれ、刺す虫であれ、蚊であれ、それぞれが何であったにせよ、再びそのものとなる。」

## **6.10.3**

「この微細な本質こそ、この世界のすべてが自己としているものである。

それが真実である。それが自己である。

**シュヴェータケートゥよ、汝はそれである（tat tvam asi）。**」

「尊き父上、どうかさらに私に教えてください。」

「よかろう、愛しい息子よ」と父は言った。

### **第10節の訳注**

**Samudrāt samudram evāpiyanti（6.10.1）：海から海へと帰る**

原文は文字どおり、海から海へと帰る、と述べている。

シャンカラやマックス・ミュラーは、海の水が雲となり、雨となって河川へ入り、再び海へ帰るという水の循環を背景にした説明と理解している。

**Sata āgamya（6.10.2）：有から来る**

6.9.2では有への合一が語られていたのに対して、ここでは有から再び現れることが語られている。

したがって、二つの節は互いに補完する関係にある。

| ---------- | -------------- |
| 6.9 蜂蜜の比喩  | 多様な存在が有へと合一する  |
| 6.10 河川の比喩 | 多様な存在が有から再び現れる |

いずれにおいても、生きものは自らとサットとの関係を認識していない。

# **第11節　樹木と生命主体の不死**

## **6.11.1**

「愛しい息子よ、もし誰かがこの大きな樹木の根元を傷つければ、その樹木は生きたまま樹液を流すだろう。

幹の中央を傷つければ、生きたまま樹液を流すだろう。

先端を傷つければ、生きたまま樹液を流すだろう。

この樹木は、生命ある自己（jīvena ātmanā）に満たされ、絶えず水分を吸い、喜びながら立っているのである。」

## **6.11.2**

「しかし、生命主体（jīva）がその一本の枝を去ると、その枝は枯れる。

二本目の枝を去ると、その枝も枯れる。

三本目の枝を去ると、その枝も枯れる。

樹木全体を去ると、樹木全体が枯れるのである。」

## **6.11.3**

父は言った。

「愛しい息子よ、まさしくそれと同じように理解しなさい。

生命主体に去られたこの身体は死ぬが、生命主体そのものは死なないのである。

この微細な本質こそ、この世界のすべてが自己としているものである。

それが真実である。それが自己である。

**シュヴェータケートゥよ、汝はそれである（tat tvam asi）。**」

「尊き父上、どうかさらに私に教えてください。」

「よかろう、愛しい息子よ」と父は言った。

### **第11節の訳注**

**Jīvenātmanā anuprabhūtaḥ（6.11.1）：生命ある自己に満たされている**

6.3.2にも登場した *jīvena ātmanā* という表現が、ここで再び用いられる。

生命ある自己は人間や動物だけでなく、樹木にも存在するものとして説明されている。

**Jīvāpetaṃ vāva kiledaṃ mriyate na jīvo mriyate（6.11.3）**

「生命主体に去られたこのものは死ぬが、生命主体は死なない。」

本文の *idam*（このもの）は文脈上、身体を指すと解釈した。

重要なのは、ここで死なないと述べられているものの原語が、直接には *ātman* ではなく **jīva（ジーヴァ）** であることである。

このジーヴァをサットやアートマンとどのような関係に位置づけるかについては、後世のヴェーダーンタ諸学派で解釈が異なる。

## **6.13.1**

「この塩を水の中に入れ、明日の朝、私のところへ来なさい。」

シュヴェータケートゥはそのとおりにした。

父は彼に言った。

「昨夜、水の中に入れた塩を取ってきなさい。」

彼は水の中を探ったが、塩を見つけることができなかった。

## **6.13.2**

塩はすっかり溶けてしまっていたからである。

「では、この水の上の方を飲んでみなさい。どんな味がするか。」

「塩辛いです。」

「中央の方を飲んでみなさい。どんな味がするか。」

「塩辛いです。」

「底の方を飲んでみなさい。どんな味がするか。」

「塩辛いです。」

「その水を捨ててから、私のところへ来なさい。」

彼はそのとおりにした。塩はずっと存在し続けていた。

父は彼に言った。

「愛しい息子よ、ここにおいても、お前はそれを見いだすことができない。しかし、それはまさしくここに存在しているのである。」

## **6.13.3**

「この微細な本質こそ、この世界のすべてが自己としているものである。

それが真実である。それが自己である。

**シュヴェータケートゥよ、汝はそれである（tat tvam asi）。**」

「尊き父上、どうかさらに私に教えてください。」

「よかろう、愛しい息子よ」と父は言った。

### **第13節の訳注**

**Atra vāva kila tat somya na nibhālayase, atraiva kila（6.13.2）**

「愛しい息子よ、ここにおいても、お前はそれを見いだすことができない。しかし、それはまさしくここにある。」

この文章には、*ātman* も *brahman* も *sat* も直接には現れない。

**Tac chaśvat saṃvartate（6.13.2）：それはずっと存在し続けている**

誰の発言であるかは原文上明示されていない。シャンカラはシュヴェータケートゥの発言として説明しているが、今回は語り手による記述として訳した。

# **第14節　ガンダーラから連れ去られた人の比喩**

## **6.14.1**

その人はそこで、東に向かって、あるいは北に向かって、南に向かって、西に向かって、叫ぶだろう。

『私は目隠しをされたまま連れてこられ、目隠しをされたまま置き去りにされたのだ』と。」

## **6.14.2**

「そこで、誰かがその人の目隠しを解き、こう教えたとする。

『ガンダーラはこの方向にある。この方向へ進みなさい。』

その人は、教えを受け、判断力を備えているならば、村から村へと道を尋ねながら、ついにはガンダーラへとたどり着くだろう。

まさしくそれと同じように、この世界においても、師を持つ人は知るのである。

その人にとって、残されている時間は、

『私が解き放たれるまでの間だけである。その後、私は合一するであろう』

というだけのものである。」

## **6.14.3**

「この微細な本質こそ、この世界のすべてが自己としているものである。

それが真実である。それが自己である。

**シュヴェータケートゥよ、汝はそれである（tat tvam asi）。**」

「尊き父上、どうかさらに私に教えてください。」

「よかろう、愛しい息子よ」と父は言った。

### **第14節の訳注**

**Gandhāra：ガンダーラ**

古代インド文化圏の北西部、現在のパキスタン北西部からアフガニスタン東部にかけて栄えた地域である。

**Ācāryavān puruṣo veda（6.14.2）：師を持つ人は知る**

*Ācārya* は師、教師を意味する。

この比喩では、師が直接その人を目的地まで運ぶわけではない。師は目隠しを解き、進むべき方向を教える。その人は教えを受けた後、自ら道を尋ね、目的地に到達する。

**Tasya tāvad eva ciraṃ yāvan na vimokṣye, atha sampatsye（6.14.2）**

第6章における解脱論を理解するうえで、極めて重要な表現である。

- *Vimokṣye*：私は解き放たれるだろう。
- *Sampatsye*：私は合一するだろう、到達するだろう。

シャンカラは、この文章を、正しい知識を得た者が、現在の身体との結びつきが終わった後にサットと合一することとして解釈する。

しかし、本文には「身体から」という表現は明示されていない。また、解脱を表す名詞 *mokṣa* が直接用いられているわけでもない。今回はそれらを本文訳に補わず、訳注に留めた。

# **第15節　死に際しての諸機能の帰入**

## **6.15.1**

「愛しい息子よ、ある人が病に苦しんでいるとき、その親族たちは彼を取り囲み、こう尋ねる。

『私が分かりますか。私が分かりますか。』

その人の言葉がまだ心へと帰入せず、心が生命息へと帰入せず、生命息がテージャスへと帰入せず、テージャスが最高の神的原理へと帰入していない間は、その人は親族たちを認識する。」

## **6.15.2**

「しかし、その人の言葉が心へと帰入し、心が生命息へと帰入し、生命息がテージャスへと帰入し、テージャスが最高の神的原理へと帰入すると、その人はもはや親族たちを認識しない。」

## **6.15.3**

「この微細な本質こそ、この世界のすべてが自己としているものである。

それが真実である。それが自己である。

**シュヴェータケートゥよ、汝はそれである（tat tvam asi）。**」

「尊き父上、どうかさらに私に教えてください。」

「よかろう、愛しい息子よ」と父は言った。

### **第15節の訳注**

**Parasyāṃ devatāyām（6.15.1〜2）：最高の神的原理へ**

6.8.6と同じ表現である。ここでも原語は *parā devatā* であって、ブラフマンではない。

**Sampadyate：帰入する、合一する**

6.8.1において、眠っている者がサットと合一すると述べられた際にも用いられていた動詞である。

本節では、言葉・心・プラーナ・テージャスという諸機能が順次、その根拠へと帰入することが説明されている。

ここで失われると述べられているのは親族を認識する働きであり、アートマンそのものの消滅が説かれているわけではない。

# **第16節　真実と虚偽の比喩**

## **6.16.1**

「愛しい息子よ、人々がある男を捕らえ、その手を取って連れてくることがある。

そして、こう言う。

『この男は物を盗んだ。盗みを働いたのだ。この男のために斧を熱せよ。』

もしその男が実際に盗みを働いた者であるならば、彼は自らを虚偽のものとする。

彼は虚偽に心を結びつけ（anṛtābhisandha）、虚偽によって自己を覆い隠し、熱せられた斧を握る。

彼は火傷を負い、そして殺される。」

## **6.16.2**

「しかし、もしその男が盗みを働いた者でないならば、彼は自らを真実なるものとする。

彼は真実に心を結びつけ（satyābhisandha）、真実によって自己を覆い、熱せられた斧を握る。

彼は火傷を負わず、そして解き放たれる。」

## **6.16.3**

「その男がそこで火傷を負わないように――

この世界のすべては、それを自己としている。

それが真実である。それが自己である。

**シュヴェータケートゥよ、汝はそれである（tat tvam asi）。**」

こうしてシュヴェータケートゥは父の教えを理解した。

実に、理解したのである。

### **第16節の訳注**

**Anṛtaとsatya：虚偽と真実**

*Anṛta* は虚偽、不真実を意味し、*satya* は真実、真なるものを意味する。

これまでサットの実在性を表すために用いられていた *satya* が、ここでは虚偽に対立する真実という倫理的な意味でも用いられている。

**Satyābhisandha：真実に心を結びつけた者**

*Abhisandha* は意図、志向、心を結びつけることなどを意味する。

シャンカラはこの比喩を、真実であるサットに自己を結びつける者と、虚偽である名称や形態に自己を結びつける者との対比として解釈する。

**Mucyate（6.16.2）：解き放たれる**

この箇所では、無実の者が拘束や処罰から解放されることを直接には意味している。

一方、6.14.2の *vimokṣye*（私は解き放たれるだろう）と関連づければ、宗教的な解脱を示唆する比喩としても理解できる。

なお、熱した斧によって有罪・無罪を判定するという記述は、古代の神判に基づくものであり、実際に真実を語る者が火傷を免れることを科学的に示すものではない。

また、6.16.3の定型句では、それまで繰り返されていた *sa ya eṣo 'ṇimā*（この微細な本質）という冒頭部分が省かれている。今回の訳でも、その原文上の違いを保持した。

## **原典を読むうえで特に重要な注意点**

第6章の本文では、後世のヴェーダーンタ哲学における中心概念であっても、以下の語が直接用いられているわけではありません。

| 概念             | 第6章における扱い                     |
| -------------- | ----------------------------- |
| ブラフマン（brahman） | 宇宙の根本原理の名称としては現れない            |
| マーヤー（māyā）     | 現れない                          |
| 無明（avidyā）     | この術語は現れないが、自己の本質を知らないことは説かれる  |
| カルマ（karma）     | 再生を説明する哲学的な術語としては現れない         |
| 輪廻（saṃsāra）    | この術語は現れない                     |
| 解脱（mokṣa）      | 名詞としては現れないが、解き放たれることは説かれる     |
| 不二一元論（advaita） | 学説名としては現れないが、advitīyaという表現がある |

したがって、第6章を初期ウパニシャッドの思想そのものとして理解する場合、後世の哲学的な術語を安易に補って読まないことが重要です。

特にシャンカラが説く、世界はブラフマンに重ね合わされた現象であり、ブラフマン自体は一切変化しないという解釈と、ウパニシャッド本文が説く、サットが自ら多数となり、生命ある自己として世界へ入り込んだという記述は、区別して読む必要があります。
