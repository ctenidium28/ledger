---
title: XOR回路のNANDゲート最小化
---
XOR回路は4つのNANDゲートで組み上げることができる。

XORを選言標準形で構成すると
```
XOR(A, B) = AND(OR(A, B), NAND(A, B))
```
となり、6個のNANDゲートが必要になるが、

XORを連言標準形で構成すると
```
XOR(A, B) = OR(
  AND(A, NAND(A, B)),
  AND(B, NAND(A, B))
)
```
となり、これは
```
not(not(A and B) and not(C and D))
= (A and B) or (C and D)
```
という関係を適用して
```
XOR(A, B) = NAND(
  NAND(A, NAND(A, B)),
  NAND(B, NAND(A, B))
)
```
とNANDゲートの数を節約することができる。

ANDとANDのORが、NANDとNANDのNANDと等しいということは、NANDゲートの最小化という面では、連言標準形が有利な傾向にあるということを示している。

実際この手の節約は典型的で、例えばnandgameのConditionでは同様の手法でNANDゲート最小の回路を組むことができる。
