---
title: max, minをビット演算で実現する
---
`x, y, z`の最大値を取る方法を考える。

原始的には、
```python
ans = x
if ans <= y: ans = y
if ans <= z: ans = z
```
と書ける。

他にも何らかの方法でソートしておき、最後の要素を抜き出す方法もある。
```lua
l = {x, y, z}
table.sort(l)
ans = l[3]
```

驚くべきことに、これらの操作をビットの上で表現する方法がある。
```python
(1<<x | 1<<y | 1<<z).bit_length()
```
`.bit_length()`はMSBを取得している。

`1<<x | 1<<y | 1<<z`で`x,y,z`のビットにフラグを立て、それらのMSBを取得することで最大が得られる。

この手法のおもしろい点は、非構成的に最大値を取り出せるところ。上記2つの方法は最大値を構成してから、それを取り出せるようにしているが、ビット演算を使った方法では
```python
(1<<x | 1<<y | 1<<z) >> 4 == 1
```
のようにして、最大値を構成する前に、最大値が4であるか尋ねることができる。

多くのアルゴリズムの文脈では、最大値を予め構成しておいたほうが何かと都合が良い場面が多いため、あまり使われることはないが、コードゴルフの文脈ではこれが役立つことがある。



ここまで来れば、最小値を取り出すには、LSBを見ればいいということになる。

```python
c = 1<<x | 1<<y | 1<<z

print(c&-c)
```
