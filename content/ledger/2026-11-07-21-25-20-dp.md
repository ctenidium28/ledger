---
title: 部分列DP
---
まず、DPの基本は数え上げ。

私は桁DPの基礎を、N以下の自然数はいくつあるか？という問題をDPを使って解くことにより理解した。

部分列DPに対しては、sの部分列はいくつあるか？という基礎的な問題を考えることができる。以下、 $|s|\eqcolon n$ とする。

当然答えは $2^n$ .
DPを使うと次のようになる。
```python
dp = [0] * (n+1)
dp[0] = 1

for i in range(n):
    # 選ぶ
    dp[i+1] += dp[i]

    # 選ばない
    dp[i+1] += dp[i]
```
部分列DPに限らず、DPには以下のことが重要である。
- dp配列が表すものを明確に把握しておく必要がある
- 可能な限り同一視を行い、dp配列を小さくする。


次にここから問題をステップアップさせる。まずは $s$ の部分列のうち、 $m$ 文字のものは何個あるか？という問題。
これは、文字数さえ同じであれば、状態を同一視できるので、
```python
dp = [[0] * (n+1) for _ in range(n+1)]
dp[0][0] = 1

for i in range(n):
    for j in range(n):
        # 選ぶ
        dp[i+1][j+1] += dp[i][j]

        # 選ばない
        dp[i+1][j] += dp[i][j]
```
と書ける。
先ほどは、選ぶ遷移と選ばない遷移に区別が必要なかったが、今回はちょっとした区別がある。


次は、 $s$ の部分列のうち、 $c$ を含むものの個数。
より正確に言えば、 $s$ の部分列のうち、 $c$ を部分列として含むものの個数。ここから実践的な問題になっていく。
```python
dp = [[0] * 2 for _ in range(n+1)]
dp[0][0] = 1

for i in range(n):
    for j in 0, 1:
        # 選ぶ
        dp[i+1][j or s[i] == 'C'] += dp[i][j]

        # 選ばない
        dp[i+1][j] += dp[i][j]
```
この書き方は桁DPの典型！

jが未満フラグのような役割をしており、一度 $c$ を含めば、それ以降も $c$ を含み、 $c$ を含んでいる状態から含まない状態への遷移は不可能という共通の構造を持っている。

これを拡張すると、次の問題が解ける。

$S$ の部分列のうち、 $T$ を部分列として含むものは何通りあるか？
```python
n = len(s)
m = len(t)

dp = [[0] * (m+1) for _ in range(n+1)]
dp[0][0] = 1

for i in range(n):
    for j in range(m+1):
        # 選ぶ
        dp[i+1][j + (j < m and s[i] == t[j])] += dp[i][j]

        # 選ばない
        dp[i+1][j] += dp[i][j]
```
桁DPの問題を複雑化させる感覚で、この遷移を書くことができる。

ちなみにこの段階で言及するのも遅い気がするが、 $S$ の部分列を走査するときにDPは役に立つが、部分文字列を走査するときには根本的に異なる手法を取ることが多い。


次は、この方向性で問題を複雑化させてみる。

$S$ の部分列のうち、 $C$ で始まるようなものは何通りあるか？

ここまで来れば、意味を考えて遷移を書くだけとなる。
```python
dp = [[0] * 2 for _ in range(n+1)]
dp[0][0] = 1

for i in range(n):
    # 選ぶ
    if s[i] == 'C':
        dp[i+1][1] += dp[i][0]
        dp[i+1][1] += dp[i][1]
    else:
        dp[i+1][1] += dp[i][1]

    # 選ばない
    for j in 0, 1:
        dp[i+1][j] += dp[i][j]
```
`dp[i][0]`: $i$ 文字目までの部分列のうち、空文字列のものの個数(当然至る所で $1$ )

`dp[i][1]`: $i$ 文字目までの部分列のうち、$C$ から始まるものの個数

と定義している。ここで注目したいのは、`sum(dp[n])`が $2^n$ 以下になるという点。
先ほどまではすべての部分列を数えていたが、ここでは意味のない状態をカウントしていない。
意味のない状態というのは、 $C$ 以外の文字から始まる部分列のことで、そのような文字列は、後にどのような文字を加えたところで、他の状態に遷移することはできないため、数えていない。


次は、

$S$ の部分列のうち、"C"と完全に一致するものはいくつあるか？

という問題を考える。これだけなら、 $S$ を左から順番に見ていけばいいが、先のためにあえてDPで解く。

そしてこの問題は直前の問題のコードを少し削るだけで正答できる。
```python
dp = [[0] * 2 for _ in range(n+1)]
dp[0][0] = 1

for i in range(n):
    # 選ぶ
    if s[i] == 'C':
        dp[i+1][1] += dp[i][0]

    # 選ばない
    for j in 0, 1:
        dp[i+1][j] += dp[i][j]
```
文字を選ぶ場合については、空文字列から $C$ を選ぶ場合のみを考えればよい。
既に $C$ から始まっていて、ほかの文字を選ぶ場合、C...と、完全一致ではなくなってしまう。


ではここで、ABCの問題を持ってこよう。

[ABC211-C](https://atcoder.jp/contests/abc211/tasks/abc211_c)

これは単純化すれば次の問題と等価である。

$S$ の部分列のうち、T="chokudai"に一致するものは何通りあるか？

直前の問題を自然に拡張することで解ける。先ほどは、

`j=0`: 空文字列
`j=1`: `c`と一致

だったが、今度は

`j=0`: 空文字列
`j=1`: `c`と一致
`j=2`: `ch`と一致
`j=3`: `cho`と一致
...

を満たす部分列を数えることになる。

以下がACコード。
```python
s = input()
t = "chokudai"

n = len(s)
m = len(t)

mod = 10**9 + 7

dp = [[0] * (m+1) for _ in range(n+1)]
dp[0][0] = 1

for i in range(n):
  for j in range(m+1):
    # 選ぶ
    if j < m and s[i] == t[j]:
      dp[i+1][j+1] += dp[i][j]
      dp[i+1][j+1] %= mod

    # 選ばない
    dp[i+1][j] += dp[i][j]
    dp[i+1][j] %= mod

print(dp[n][m])
```
私はここまで到達するのに、随分と時間がかかってしまった。この問題のこの解法は全探索からは少しばかり離れた位置にあり、全探索から削っていく方針で考えるには骨が折れるし、かと言ってこの解法をいきなり理解しようとしても深い理解には繋がらないように思えて仕方ない。ここまで順番に追って来れば分かるが、この解法では、c, h, o, k, u, d, a, iの順番に合致しない部分列をはじめから数えていない。

これはあくまでイメージだが、DPのセル一つ一つには同値類の代表元が入っていると意識するとDPは途端に分かりやすくなる。よりコーディングに近い表現をすれば、DPというのは、全探索木を層ごとに見て、将来的に振る舞いが同じと見做せるノード同士をマージした上での全探索と言えるだろう。
「DPは全探索」「DPはDAG」とよく言われているが、なるほど確かに、私の今の理解を雑に一言でまとめるならそうなるのかもしれない。
